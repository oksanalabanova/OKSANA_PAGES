Ellipsoid on teist järku pind ruumis, mis saadakse ellipsi venitamisel kolmes ruumimõõtmes.

• Kui ellipsoidi keskpunkt asub koordinaatide alguspunktis (0;0;0), on kanooniline võrrand:
x²a² + y²b² + z²c² = 1
• Korrutades kanoonilist võrrandit ühise nimetajaga a²b²c², saame üldvõrrandi kuju:
Ax² + By² + Cz² + D = 0
kus kordajad on:
A = b²c²,   B = a²c²,   C = a²b²,   D = -a²b²c².
(Mugavuse mõttes taandatakse üldvõrrandi kordajaid suurima ühisteguriga). Joonisel on x-, y- ja z-telg värvitud vastavalt a, b ja c poolteljele.
