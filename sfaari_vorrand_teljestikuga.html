Sfääriks nimetatakse fikseeritud punktist (sfääri keskpunktist) võrdsetel kaugustel asuvate punktide hulka ruumis.

• Kolmemõõtmelises ruumis moodustub selline punktihulk ringjoone pöörlemisel ümber oma diameetri. Seega on sfäär pöördpind.

• Kui sfääri keskpunkt asub koordinaatide alguspunktis, on kanooniline võrrand:
x² + y² + z² = R²
• Korrutades võrrandit läbi vabalt valitud kordajaga A, saame üldkuju:
Ax² + By² + Cz² + D = 0
kus A = B = C ≠ 0 ning D = -A · R². Joonisel on iga telg värvitud vastavalt oma kordajale (A - oranž, B - roheline, C - sinine), ja x-teljel on märgitud raadiuse R pikkus.
