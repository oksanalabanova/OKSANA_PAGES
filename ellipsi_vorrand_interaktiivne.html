1. Võta kanooniline võrrand:
(x - m)²a² + (y - n)²b² = 1
2. Korruta võrrandi mõlemad pooled läbi ühise nimetajaga a²b²:
b²(x - m)² + a²(y - n)² = a²b²
3. Ava sulud ja vii kõik liikmed vasakule poole:
b²(x² - 2mx + m²) + a²(y² - 2ny + n²) - a²b² = 0
4. Rühmita liikmed üldkujule:
Ax² + Cy² + Dx + Ey + F = 0
kus kordajad on:
A = b²,   C = a²,   D = -2b²m,   E = -2a²n,   F = b²m² + a²n² - a²b².
