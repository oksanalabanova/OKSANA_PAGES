Ringjoone kanooniline ja üldvõrrand

Lohista keskpunkti punast täppi koordinaatteljestikul või kasuta liugureid

Keskpunkti saab otse hiire/sõrmega lohistada!
Kanooniline võrrand:
Üldvõrrand (sulud avatud):
Keskpunkti x-koordinaat (a) 0
-8 8
Keskpunkti y-koordinaat (b) 0
-8 8
Ringjoone raadius (R) 3
0.5 8
Ava kanoonilise võrrandi sulud ruutude vahe valemiga:
(x - a)² + (y - b)² = R²
x² - 2ax + a² + y² - 2by + b² - R² = 0
Koonda sarnased liikmed:
x² + y² + Dx + Ey + F = 0, kus:
D = -2a, E = -2b, F = a² + b² - R².
